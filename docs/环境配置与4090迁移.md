## 实时日志与下载策略
`tail -f logs/progress.log` 查看总进度；详细下载和安装日志在 logs/，不纳入 Git。
南京大学索引实际链接至官方存储；阿里云 direct wheel 实测较慢，最终采用上海交大实际托管地址并用6路分段下载。下载器严格验证 HTTP 206 和 Content-Range；已有顺序下载部分保留。
wheel 缓存也放移动硬盘 wheels/；Conda 包缓存仍使用本机。
SAN_CLIP_WEIGHTS 环境变量指定本地 CLIP 权重，避免自动下载和 NTFS 符号链接依赖；不设置时保留官方默认行为。
`source deployment/env.sh` 加载本机路径配置；迁移时修改 SAN_ROOT、SAN_STORAGE、CUDA_HOME。该文件清除已有 ROS PYTHONPATH，防止污染隔离环境。
