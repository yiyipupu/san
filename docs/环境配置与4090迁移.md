### 兼容性调整记录
原始 requirements 未限制 SciPy/scikit-image，解析器会下载多个与 NumPy 1.22.4 不兼容的新版本。已固定 scipy==1.10.1、scikit-image==0.20.0、h5py==3.10.0、matplotlib==3.7.5，避免反复回溯。最终版本以成功后的 lock 文件为准。

### 迁移操作草案（验证完成后补录结果）
1. 复制或 clone 此 Git 仓库及部署分支到目标机。
2. 复制硬盘 SAN 目录中的 weights/、cache/、wheels/，核对部署校验清单。
3. `conda create -n instructpart-san python=3.10 pip -y`，激活环境。
4. 指定目标机 `CUDA_HOME`（11.8）和 `SAN_STORAGE`，运行 `bash deployment/rebuild.sh`；MAX_JOBS=2 控制编译内存。目标机器的 GPU 架构由本机编译探测，4090 为 8.9。
5. 修改 deployment/env.sh 中路径，并指定 SAN_PYTHON 与 SAN_IMAGE；`bash deployment/run_forward.sh`。目标机需一张普通 RGB 图片，不需要完整数据集即可验收前向。
6. 在单卡前向通过后，再执行官方 train_net.py 的训练流程。训练必须准备对应标注与数据注册，记录 batch、输入尺寸、随机种子、GPU 数量和输出 checkpoint；如需证明训练可用，应验证 loss、反向及参数更新，而不是仅启动任务。
